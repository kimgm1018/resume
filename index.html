자기소개서

저는 비전공자에서 실무형 AI 개발자로 성장한 개발자 김강민입니다.

국어국문학과에서 언어의 구조와 의미를 탐구하며 분석적 사고를 기르고, 한국어데이터정보학(정보통계학·컴퓨터공학 부분 이수)을 통해 데이터 처리와 프로그래밍 역량을 함께 쌓았습니다.
비전공자로 시작했지만, 스스로 Python·ML·DL·LLM 등을 학습하며 실제 서비스 개발에 참여할 수 있을 만큼의 전문성을 갖추게 되었습니다.

대학교 재학 중에는 혐오표현 탐지 모델을 직접 학습·검증하는 연구 프로젝트를 수행했습니다. 데이터 전처리부터 모델 학습, 평가까지 전 과정을 직접 진행하며 자연어처리(NLP)의 핵심 개념과 모델링 절차를 깊이 이해하게 되었습니다.
이러한 경험은 이후 실무 프로젝트에서 AI 모델을 설계하고 성능을 개선하는 데 큰 밑거름이 되었습니다.

현재 근무 중인 회사에서는 LangChain·LangGraph 기반의 AI 서비스 개발을 담당했습니다.
구체적으로는 RAG 기법을 활용한 위험 약물 탐색 챗봇, 환자별 유전자 검사 결과 요약 기능, 의뢰 및 서비스 예약 챗봇을 개발했습니다.
또한 FastAPI 기반의 백엔드 구축과 프론트엔드 연동까지 구현하여 기획부터 배포까지의 전 과정을 경험했습니다.

현재는 CYP2D6 유전자의 GenoType을 자동 판독하는 AutoCalling 알고리즘을 개발했으며, 이를 범용적으로 사용할 수 있도록 유연성을 고려하여 구현하고 있습니다.

SSAFY 관통 프로젝트 할래말래에서는 Django·Vue 기반 풀스택 서비스에 LangGraph ReAct 챗봇과 KNN 추천 엔진을 통합하여 실서비스로 배포했습니다.
1,500종 이상의 보드게임 데이터에 대해 조건·유사·개인화 3단계 추천을 제공하고, 챗봇이 추천 도구를 자동 호출해 SSE 스트리밍으로 응답하는 구조를 설계·구현했습니다.
Google Cloud Run, Cloud SQL, Firebase Hosting을 활용한 클라우드 배포 경험을 통해 의료 AI 서비스에서 쌓은 역량을 소비자 대상 플랫폼으로 확장했습니다.

이러한 경험을 통해 저는 단순한 모델 구현을 넘어, 실제 사용자가 체감할 수 있는 AI 서비스를 설계·개발하는 역량을 갖추게 되었습니다.
앞으로도 언어와 데이터를 잇는 기술을 통해 실질적인 가치를 창출하고, 새로운 문제를 스스로 해결해내는 개발자로 성장해 나가겠습니다.
